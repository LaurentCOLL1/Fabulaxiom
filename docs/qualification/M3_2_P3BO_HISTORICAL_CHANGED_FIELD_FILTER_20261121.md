# P3bo — Filtrer les IDs d'événements fictifs par champ réellement changé (21/11/2026)

Dans l'atelier React fictif **NON MONTÉ**, le nouveau filtre d'historique comporte cinq choix : tous, titre modifié, note modifiée, ancre modifiée, révision source modifiée. Un champ est « modifié » uniquement si la valeur de cette même propriété est différente de sa version **immédiatement précédente pour le même événement** ; la première version n'est pas une correction. Les tombstones de retrait qui conservent les champs à l'identique ne sont pas des modifications. Tous les autres filtres existants (source exacte, ancre, roman, scène, statut, date et type temporel) s'appliquent à la **même version** amendée, sans union entre anciennes versions.

Le choix affiche uniquement les IDs des événements correspondants, jamais leurs titres/note/justification historiques tant qu'une sélection explicite n'a pas été effectuée. Changer de filtre efface l'ID sélectionné et revient à la première page ; réinitialisation générale inclut ce nouveau sélecteur. Types de champs invalides refusés.
